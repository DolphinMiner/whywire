# Request

This is a synthetic learning example, not a production incident.

A caller removes an item while work for it is still pending. Sometimes the
item becomes visible again. Read `app.py`, run it locally, and explain the
sequence that produces the observed result. Diagram the relevant boundary,
identify the invariant and who should own it, and evaluate the guarded variant
without assuming that a single-process demonstration proves concurrent safety.

Use `app.py` as the input. Leave `explanation.md` closed until you have written
your own explanation; it is a worked example, not additional source evidence.
