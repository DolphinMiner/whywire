Read an item. Follow its path.

A caller asks for an item. This tiny cache-aside example returns its value, using a local cache to avoid reading the origin again.

About this guide
Who this is for
A developer meeting this code for the first time.
What this guide covers
Two sequential reads of one unchanged item. Synthetic Python objects: no server, network, or database.

Ordering in this example

Branches & timing
If the origin changes
An existing cache entry is not refreshed. This fixture contains no invalidation or expiry policy.
Outside this guide
  • Missing keys, origin failures, concurrent requests, process restarts, and distributed consistency.
  • The example makes no production freshness or latency claim. Its runnable check covers equal responses and the origin read count.
